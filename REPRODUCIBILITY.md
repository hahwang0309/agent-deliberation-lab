# Paper 1 reproducibility

Use the [curated v2 release](https://github.com/hahwang0309/agent-deliberation-lab/releases/tag/paper1-reproduction-v2-2026-10-26) and its README for tested commands. The archive separates runnable offline analysis, the frozen experimental source, and optional paid coding references. The general web platform is not required.

The fixed public dataset is [haha0309/agent-deliberation-study1 at c13fd45](https://huggingface.co/datasets/haha0309/agent-deliberation-study1/tree/c13fd45abfafc9f0bcc5b8157d8ea73038138ae8).

The quick start refits 15 E1–E5 contrasts across three models, renders all six main figures from archived estimates, and audits the released coding merge. It does not refit all 42 registered rows or every exploratory analysis. Offline commands make no model API calls. See the package's CURATION.md and verification/v2-check.json for the exact tested scope.

The [v1 release](https://github.com/hahwang0309/agent-deliberation-lab/releases/tag/paper1-reproduction-2026-10-26) remains unchanged.
