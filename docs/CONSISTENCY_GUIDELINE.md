# 행정조사 중복 판정 AI 일관성 지침서

> 이 결과만 기반으로 시스템이 스스로 수정·운영할 수 있게 설계

## 1. 용어 및 라벨 정의(고정)

AI는 중복 여부를 다음 3개 라벨 중 하나로만 판정한다:

| 라벨 | 정의 |
|------|------|
| **중복(duplicate)** | 조사 A와 B의 대상·내용·자료요구·절차 중 대부분이 동일하거나 완전히 일치 |
| **부분중복(partially duplicate)** | 조사 A와 B가 일부라도 겹치는 영역이 있는 경우.<br>**하위집합 관계(=B ⊂ A 또는 A ⊂ B)도 부분중복으로 확정** |
| **비중복(non-duplicate)** | 조사 A와 B가 대상·내용·자료·절차 중 겹치는 영역이 전혀 없을 때만 |

### ✅ 핵심
- **하위집합 = 부분중복**
- **"완전히 동일하지 않다" = 비중복이 아니라 "겹치는 부분이 있으면 부분중복"**

## 2. 쟁점별 판정 규칙 (항상 이 순서로 적용)

### 쟁점 1) 조사 대상 동일성
- **동일** → 중복
- **일부만 포함/하위집합** → ✅ **부분중복**
- **전혀 다름** → 비중복

### 쟁점 2) 조사 내용 유사성
- **동일한 자료 요구 + 동일한 검사 방식** → 중복
- **일부 항목이 같고 일부는 다르면** → ✅ **부분중복**
- **검사 방식·자료요구·절차가 완전히 다르면** → 비중복

### 쟁점 3) 법적 근거
- **같은 조항(같은 항)** → 중복
- **같은 조문(제74조)이라도 다른 항(1항 vs 2항)이라면**,
  - 대상 또는 절차가 서로 구분됨 = 비중복 근거로 활용 가능
  - 단, 다른 항이더라도 대상을 일부 공유하면 → ✅ **부분중복**

### ✅ 중요
- **"법적 근거가 다르다 = 자동 비중복"이 아니며**
- **대상 또는 내용이 겹치면 부분중복**

## 3. "최종 판정 알고리즘"

쟁점별 라벨을 아래 규칙으로 종합한다:

| 라운드 결과 조합 | 최종 판정 |
|-----------------|----------|
| 세 쟁점 모두 중복 | **중복** |
| **하나라도 부분중복 포함** | ✅ **부분중복** |
| 세 쟁점 모두 비중복 | **비중복** |

### ✅ 중요
**"부분중복"이 단 하나라도 있으면 최종 결과는 부분중복**

이것만 적용하면 두 실험의 결과가 항상 동일해짐

## 4. 합의도 처리 규칙

합의도가 100%라도:
- 발언 내용 중 하위집합 언급
- "일부 겹침", "일부분 동일", "중복되는 요소 존재"
- 이런 표현이 단 1회라도 등장하면
  
→ **부분중복 판정 유지**

"전원 동일 + 겹침 인정 없음" → 비중복 가능

### ✅ 즉
**부분중복 표현이 단 한 번이라도 등장하면 절대 비중복이 될 수 없음**

## 5. 모더레이터 발언 생성 표준

모더레이터는 아래처럼 판정한다:

- **"대상이 완전히 동일하지 않다"**라고 발언되더라도
  - → 겹치는 부분을 언급했다면
  - → **부분중복**

- **"법적 근거가 다르다"**가 언급되어도
  - → 대상/내용이 겹친다고 발언되면
  - → **부분중복**

## 6. 예외 금지 규칙

### ✅ 다음과 같은 판단은 금지한다:

❌ "완전히 동일하지 않다 → 비중복" **(금지)**
❌ "법적 근거가 다르다 → 자동 비중복" **(금지)**
❌ "하위집합이므로 비중복" **(금지)**
❌ "일부만 겹치므로 비중복" **(금지)**

**✅ AI가 이 금지 규칙만 지키면 결과는 절대 흔들리지 않음**

## 7. 결과 자동 보정 로직

만약 쟁점별 판정 결과가:

```
대상: 비중복
내용: 부분중복
법적근거: 비중복
```

이런 식으로 섞여 있으면,

→ **최종 결과는 무조건 부분중복**

## 8. 실제 적용 시 문장 예시(모더레이터)

```
"행정조사 B는 도시개발사업 중 민간참여 방식에 한정된 하위집합이므로,
대상이 완전히 동일하지 않더라도 일부 영역을 공유하므로 부분중복으로 판정합니다."
```
